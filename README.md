# ✋ Hand Gesture Drawing

웹캠과 손 제스처로 그림을 그리는 AI 기반 인터랙티브 드로잉 앱
> 손을 카메라에 들이대고 검지로 그림을 그려보세요!

---

## ✨ 핵심 기능

- **제스처 인식 그리기** — 검지 하나로 캔버스에 자유롭게 그리기
- **베지어 곡선 스무딩** — 손떨림 없이 부드러운 선
- **멀티스레드 처리** — MediaPipe를 별도 스레드로 분리해 FPS 안정화
- **제스처 버퍼 스무딩** — 최근 8프레임 기반 안정적인 제스처 인식
- **거리 비율 기반 판별** — 손 기울기에 강인한 draw/pen_up 구분
---

## 🤚 제스처 조작

| 제스처 | 동작 |
|--------|------|
| ☝️ 검지만 펴기 | 그리기 |
| ✊ 주먹 쥐기 | 펜 올리기 |
| ✌️ 브이 | 색상 변경 |

---

## ⌨️ 단축키

| 키 | 동작 |
|----|------|
| `S` | 캡처 저장 (`saves/` 폴더) |
| `C` | 캔버스 초기화 |
| `+` / `-` | 브러시 크기 조절 |
| `Q` | 종료 |

---

## 📦 실행 파일 다운로드

## 🧰 기술 스택

| 항목 | 내용 |
|------|------|
| 언어 | Python 3.11 |
| 손 인식 | MediaPipe Hand Landmarker |
| 영상 처리 | OpenCV |
| 렌더링 | NumPy, Pillow |
| 선 스무딩 | Bezier Curve (Catmull-Rom) |
